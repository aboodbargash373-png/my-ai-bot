# 🤖 Smart Enterprise Customer Service AI Chatbot

An intelligent, context-aware AI chatbot engine designed for businesses and enterprise customer support. Built using *Streamlit, **Google Gemini 3.6 Flash, and **PyPDF*, this application ingests dynamic company knowledge bases (PDFs/Documents) to deliver accurate, fast, and highly reliable customer responses in real time.

---

## ✨ Features
* *📄 Dynamic Knowledge Retrieval:* Upload company data, FAQs, or product catalogs in PDF format to instantly train the chatbot.
* *⚡ Gemini 2.5 Flash Powered:* High-speed, highly context-aware responses with low latency.
* *💬 Intuitive User Interface:* Clean, reactive chat interface built using Streamlit.
* *🔒 Privacy & Security First:* Zero hardcoded API keys; designed to run with secure environment configurations.

---

## 🛠️ Tech Stack
* *Language:* Python 3.10+
* *Frontend/UI:* Streamlit
* *LLM Engine:* Google Gemini API (gemini-2.5-flash)
* *Document Processing:* PyPDF (pypdf)
